3. 最终架构：SafeWorldF1 —— 一个 shared L3，K 个 candidate 查询，后果知识全部摊销

Shared observation camera / ego history / navigation
→
Frozen Alpamayo-1.5-10B prefill 一次 prompt prefill（production predict() 内 hook）
→
L3 = full_L2[−1] [4096]，bit-exact 证明为最终层 hidden 序列末行
→
K=8 branches reasoning + diffusion trajectories
→
SafeWorldF1 head 1,708,871 参数，1.19 ms
For candidate i in group g (K=8, candidate-independent, no cross-candidate attention): planned_trajectory_i [64,2] -> trajectory encoder -> query_i query_i × L3 scene feature -> candidate-conditioned latent z_i score head: ŷ_{g,i} = m̂_g + S·tanh(û_{g,i}/S) (§4.1) auxiliary heads: future ego [64,2] / progress / collision / offroad (training-only) selection: argmax_i ŷ_{g,i} (deterministic)

定型的设计决策（各自有专属修复阶段）

  • Group-mean / candidate-residual 分解（C0）：官方分数 98.2% 是 group-level offset，分解后 ranking 信号才可学。
  • Bounded residual（D0/D）：S·tanh(·/S) 修复 rank/centered 梯度冲突（cosine −0.22…−0.41 → +0.02…+0.34，spread −48%）。
  • Inner-validation-only checkpointing（E0，CONSTRAINED_SELECTOR_FIRST）。
  • Candidate independence：无 cross-candidate attention，score 不依赖候选集合构成。
  • Amortized consequence knowledge：future/progress/collision/offroad 仅作辅助监督；deletion test —— 推理时删除全部辅助头，score bit-identical → 不是 world model（推理路径上零 state prediction）。

被关闭的替代架构（全部有 CI 支持的判定）

  • Compressed-L2 V1（32-token 均值池化）：内容为负贡献（−0.032，zeroing 反而更好），T26G-B 关闭。
  • FULL 3086-token reader：matched 容量下劣于 LASTTOKEN 两个 primary（FM1 M1），关闭。
  • E1 selector loss 作为部署目标：前瞻验证买不到 top-1、卖掉 regret（FN1 N3），关闭；E1 的 +0.083 top-1 是回溯性 cohort 上的一次性现象。
  • Expected-regret softmax（E0 拒绝）：selector 自信地错时梯度恰好消失（对照实测：frozen loss 饱和于 ~24.9，softmax 族梯度 ~1.3×10⁻⁶⁰）。
Same-prefill capture（论文 C1 / Fig.2）： 候选与表征来自同一次 prefill 事件；exactly-one-prefill 断言 + capture-time tensor hash 链 + L3 == full_L2[-1] 519/519 bit-exact，排除"表征与候选异源"混淆。这是 F0→FP0→FR0→FS0 历史闭包失败链换来的协议。

4. 冻结公式与目标函数（全部机械推导，零调参）

4.1 分数分解与有界残差（C0 + D0，全臂共用）

ŷ_{g,i} = m̂_g + r_{g,i} m̂_g : group-mean head（candidate 无关，读 scene 表征） r_{g,i} = S · tanh( û_{g,i} / S ), S = 0.67 û_{g,i}: candidate-conditioned raw residual（zero-init residual head）

S=0.67 由 D0 从 within-group 官方分数 spread 分位数机械推导；zero-init residual head 意味着任何 score-probe 在初始化时 vacuous（F0-B 记录的陷阱），且 shared-trunk 梯度在初始化恒为零 —— 这直接决定了 4.3 的 scale-match 统计量选择。

4.2 Checkpoint-only objective（部署臂 P_L3_CKPT 的训练目标）

L_ckpt = 0.5·L_centered + 0.25·L_future + 0.1·L_group_mean + 0.1·L_progress + 0.1·L_collision + 0.1·L_offroad （SmoothL1 beta 按目标尺度 scale-matched；系数自 C0 起冻结未改）

其中 future/progress/collision/offroad 四个头即"摊销的后果知识"：训练时把闭环后果压进表征读取器，推理时整体删除，score 不变（deletion test）。

4.3 E0 selector loss（P_L3_SEL 臂；FN1 已判定不部署，公式保留为论文 §4.4 + supp lemma）

Tied-best set: B_g = { i : y_max − y_i ≤ ε }, ε = 1e-6 (复用 RANK_EPS) Pair weight: w_j = y_max − y_j （true regret, j ∉ B_g） Per-pair loss: (w_j / |B_g|) · softplus( −(s_i − s_j) / τ ), i ∈ B_g, j ∉ B_g Batch pooling: Σ weighted pair losses / Σ pair weights τ = 0.043 = ceil_0.001( median positive oracle-best gap ) (raw 0.04298818) coef = 0.026 (RMS dL/ds scale-match at equal scores; unrounded 0.02643769) 替换关系: REPLACE L_rank_margin（系数 1.00,整体移除）,非叠加
  • 为何选这个族（E0 决定性判据 5）：目标函数存在的意义是修复 top-of-list；regret-weighted logistic 在"selector 自信地错"处梯度饱和（有界、非零），而被拒绝的 expected-regret softmax 在同一处梯度消失。
  • All-tie group 语义（冻结结构规则）：tied-best 集为整组时不存在 (best, rest) 对，损失为确定性精确零——但实现上返回的是非空零权重对。FN1 中 169/1,575 组（10.7%）为 all-tie，SEL 布线经 D-pooling 时其守卫只覆盖空对 → 15 个 SEL run 全部即时 NaN；predict 阶段 sel==treated bit-identity 检查在 lock 之前捕获，修复守卫为 numel()==0 or pw.sum()==0.0 并重训（mid-run repair 001，零科学影响）。教训：合成一致性测试必须包含 all-tie score batch。

4.4 指标定义（唯一监督 = AlpaSim official scene score ∈ [0,1]）

selected regret_g = y_{g,oracle} − y_{g,selected} (scene-macro 聚合) tie-aware top-1_g = 1[ y_{g,selected} ≥ y_{g,max} − ε ] K-subsets: K2 / K5 / K8（frozen subset rule）; 95% CI = 10k paired scene bootstrap seeds: FM1 = 20260803, FN1 = 20260809（= 各自 record 日期,冻结规则）
指标边界不变： submetric（future/progress/collision/offroad）不得手工重组 official score（anti-gaming）；WoTE 的 NC/DAC/TTC/Comfort/EP/PDMS、NAVSIM、nuPlan 均不进入本程序。

14. 当前科学解释

已经证明（全部 CI 支持、预注册）

  • L3 scene value：真实、因果、scene-specific，三次复现（E6/M3/N2），效应随功效增强。

  • L3 与 tuned geometry incumbent 在两个 primary 上统计等价（N1，power 0.80）；pairwise ranking 上 L3 CI 支持地更强。
  • 后果知识可被摊销进 1.7M/1.19ms/3.5MB 的头（deletion test 通过）。

已经否定 / 永不再测

  • FULL reader 增益（关闭）；compressed-L2 V1（关闭）；E1 selector loss 部署价值（关闭）。
  • 历史 366-group cohort 的 full-L2 复原（物理不可能，FS0）。
  • "L3 优于 legacy" 的 promotion（FN1 终审否定；35 sealed 永久封存）。

边界之外（新预注册才可触碰）

  • 预测接回打分路径（W0 探索线，§16）。
  • full sequence 对生成式/dynamics头的价值（FM1 只关闭了判别式任务）。
  • K≫8、多 VLA、多 simulator 的外推。
一句话的领域启示（论文 Discussion 的姿态）： 选择增益在强生成器 + K=8 下的诚实尺度就是百分之零点几的 regret——这正是 CI、功效解析与预注册必要的原因；本文把"表征重用何时值得"的答案从 anecdote 变成了带边界的测量。
